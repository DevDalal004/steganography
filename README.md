 Image Steganography App
A web-based tool to encode secret messages into images and decode messages from images, using simple Least Significant Bit (LSB) steganography. Built with plain HTML, CSS, and JavaScript, this project runs entirely in the browser with no server required.


🚀 How to Set Up and Run the Project
1.Clone or Download the Repository
 bash
 git clone https://github.com/your-username/image-steganography-app.git
 cd image-steganography-app

2. Run the Application
No installation is needed. Open the index.html file directly in your browser:
  *Windows: Double-click index.html
  *macOS/Linux: Right-click → Open With → Your Browser

📦 Dependencies and Configurations
This project uses no external libraries or frameworks. All logic is handled with native:
 *HTML5
 *CSS3
 *JavaScript (ES6)

✅ No package installation
✅ No build steps
✅ No server or backend required

✨ Features
 *Upload any image and embed a hidden message.
 *Extract and display the secret message from an image.
 *Download the newly encoded image with your hidden message.
 *Responsive and modern UI design.
